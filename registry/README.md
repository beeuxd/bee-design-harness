# @bee shared recipe registry

shadcn-compatible registry items promoted from projects via `recipe-harvest` Step 3 — compositions that shipped through the gates somewhere and are now installable anywhere:

```bash
pnpm dlx shadcn@latest add <registry-url>/<recipe-name>
```

or browsed/installed through the shadcn MCP (ships with role-engineer). Promotion rule: only gate-passed recipes enter; each item's description names the situation it serves and its provenance project.
