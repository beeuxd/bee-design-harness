# Recipes — approved component compositions

Maintained by `recipe-harvest`. A recipe is a composition of primitives that shipped: it passed hifi-gate and the ship gate on a real screen. Recipes are earned, never invented — a row here without provenance is a defect. Reuse-first checks this file (and the registry) before composing anything from scratch.
