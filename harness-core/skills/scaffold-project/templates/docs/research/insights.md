# Research Insights

Produced and maintained by `/insight-loop`. Every insight must trace to verbatim quotes in `docs/research/raw/` — an insight with no source row is a defect, not a finding. INS-IDs are permanent; never renumber.

## Insight Inventory

| ID | Insight (one sentence, in the users' terms) | Supporting quotes (verbatim, with source) | Sources | Confidence | Status |
|----|---------------------------------------------|-------------------------------------------|---------|------------|--------|
| INS-001 | | "…" — `raw/<file>.md`, p0X | | High / Medium / Low | Active |

**Confidence rubric** — High: ≥3 independent sources, no contradicting evidence. Medium: 2 sources, or 3+ with minor contradictions recorded below. Low: single source, or user-provided without raw data (`unvalidated`).

**Status vocabulary** — `Active`: current, citable downstream. `Superseded by INS-XXX`: reworded/split in a later run; row stays for ID stability, downstream docs should migrate to the successor. `Retired`: contradicted by newer evidence or its source was withdrawn; never citable, reason noted in the ledger.
