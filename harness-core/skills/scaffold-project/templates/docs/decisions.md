# Standing Decisions

Persisted director rulings — the harness's approval-persistence layer. When a verdict includes a
standing instruction ("always X", "never ask about Y again", "default to Z"), it's recorded here
(process/scope rulings) or in `design/taste-rules.md` via `taste-retro` (visual rulings). Loops
consult this file before presenting a verdict: a question already answered by a standing decision
is applied and cited in the ledger, not re-asked. **The exit verdict of a loop is never
auto-resolved** — this file eliminates repeat questions, not director control.
