# Review Queue

The director's inbox — one entry per decision waiting on a human verdict, written by the loops
and gates alongside their `Verdict: PENDING` ledger markers. Each entry carries the draft, the
reasoning, and the evidence, so ruling takes a glance, not an excavation. Entries flip to
RESOLVED (never deleted) when the director rules; the statusline counts OPEN entries.
